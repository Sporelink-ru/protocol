# Sporelink Protocol

Открытая спецификация федеративной сети серверов Minecraft.
Статус: **Draft v0.1** (в разработке).

## Что это
Протокол, который позволяет независимым серверам объединяться
в единую сеть с общим аккаунтом, экономикой и репутацией —
без центрального сервера-владельца.
